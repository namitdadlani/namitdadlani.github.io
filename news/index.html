AI coding agents generate more code, but not more software

AI coding assistants help developers write significantly more code, but a new Harvard study shows they do not increase overall software output. Researchers analyzed 300 million work events across hundreds of firms and found that efficiency gains during coding are completely absorbed by a human review bottleneck. Following the introduction of AI coding agents, total lines of code jumped by 30 percent, while the average review time for pull requests ballooned by 49 percent.
